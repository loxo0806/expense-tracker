Python Expense Tracker.

This project allows users to track their expenses, store them in a file, and generate reports such as:

- Total expenses
- Expenses by category
- Highest expense recorded

The program uses basic Python concepts like functions, dictionaries, file handling, and control flow.


Features.

- Add new expenses
- Save data to a file (`data.txt`)
- Read and process stored data
- Calculate total expenses
- Group expenses by category
- Identify the highest expense
- Interactive CLI menu


Technologies Used.

- Python 3
- File handling (`open`, `read`, `write`)
- Dictionaries and lists
- Functions and modular design
